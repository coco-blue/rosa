Elementos básicos para escribir código

¿Cómo se estructura un código JavaScript?

Un programa de JavaScript se forma con instrucciones que indican a la computadora qué debe realizar. Estas instrucciones pueden declarar variables, realizar operaciones, mostrar información o ejecutar funciones.

Partes principales

  1. Comentarios: explican el código y no se ejecutan.
  2. Variables: almacenan información.
  3. Instrucciones: indican las acciones que se realizarán.
  4. Condiciones: permiten tomar decisiones usando if y else.
  5. Funciones: agrupan instrucciones para poder utilizarlas cuando se necesiten.

Ejemplo de estructura

// Este es un comentario
let nombre = "Ana";
let edad = 16;

if (edad >= 18) {
    alert("Eres mayor de edad");
} else {
    alert("Eres menor de edad");
}

function mostrarNombre() {
    alert("Hola " + nombre);
}

mostrarNombre();

En el ejemplo se declara el nombre y la edad, se utiliza una condición para revisar la edad y se crea una función para mostrar un saludo.

Formas de agregar JavaScript a HTML

1. JavaScript interno

Se escribe dentro de la etiqueta <script> en el mismo archivo HTML.

<script>
    alert("Hola mundo");
</script>

2. JavaScript externo

El código se guarda en un archivo separado con extensión .js y se conecta al HTML con la etiqueta script.

<script src="codigo.js"></script>

Separar el código JavaScript del HTML ayuda a mantener los archivos más ordenados.

Recomendaciones

  • Escribir correctamente las mayúsculas y minúsculas.
  • Usar llaves { } para delimitar bloques de instrucciones.
  • Colocar nombres claros a las variables y funciones.
  • Utilizar comentarios para explicar partes importantes.
