JavaScript

Lenguaje de programación para páginas web

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar interactividad y movimiento a las páginas web. Con él podemos responder a las acciones del usuario, validar formularios, mostrar mensajes y modificar el contenido de una página.

¿Para qué sirve?

  • Mostrar mensajes con alert().
  • Solicitar información con prompt().
  • Confirmar una acción con confirm().
  • Realizar operaciones matemáticas.
  • Modificar textos, imágenes y otros elementos de HTML.

Variables

Las variables sirven para guardar datos que podemos utilizar después. En JavaScript se pueden declarar principalmente con let y const.

  • let: se utiliza cuando el valor puede cambiar.
  • const: se utiliza cuando no queremos reasignar el valor.
  • var: es una forma antigua de declarar variables.

Tipos de datos

  • String: texto, por ejemplo "Hola".
  • Number: números, por ejemplo 15 o 3.5.
  • Boolean: valores verdadero o falso (true / false).

Ejemplo de JavaScript

El siguiente ejemplo solicita el nombre de una persona y después muestra un saludo.

let nombre = prompt("Escribe tu nombre");
alert("Hola " + nombre);

Aquí aparecerá el saludo.
