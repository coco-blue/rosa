DOM (Document Object Model)

Modelo de objetos del documento

¿Qué es el DOM?

El DOM (Document Object Model) es una representación de una página HTML en forma de objetos. JavaScript puede utilizar el DOM para encontrar elementos, cambiar su contenido, modificar sus estilos y responder a eventos.

Por ejemplo, cuando presionamos un botón y cambia un texto de la página, JavaScript puede realizar ese cambio mediante el DOM.

¿Para qué sirve?

  • Seleccionar elementos HTML.
  • Cambiar textos y contenido.
  • Modificar atributos y estilos.
  • Crear o eliminar elementos.
  • Detectar acciones del usuario, como hacer clic.

Formas de seleccionar elementos

MétodoFunción
getElementById()Busca un elemento por su identificador (id).
getElementsByClassName()Busca elementos que tengan una clase.
getElementsByTagName()Busca elementos por el nombre de su etiqueta.
querySelector()Selecciona el primer elemento que coincide con un selector CSS.

Ejemplo práctico del DOM

Al presionar el botón, JavaScript busca el elemento que tiene el id "texto" y cambia su contenido.

Este es el texto original.

document.getElementById("texto").textContent = "Texto nuevo";

Eventos

Los eventos son acciones que ocurren en la página, por ejemplo hacer clic en un botón, escribir en un campo o cargar el documento. JavaScript puede ejecutar una función cuando sucede un evento.

onclick: ocurre cuando el usuario hace clic en un elemento.
